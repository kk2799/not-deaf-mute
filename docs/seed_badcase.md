# Seed Robustness Supplement (badcase 附件)

本文档是主论文的种子稳健性补充材料，随投稿作为附件提交。
主论文正文汇报的种子为 **42 / 3407 / 2027**（三种子均值±标准差）；
本文档详细列出全部五个种子（42 / 123 / 2026 / 2027 / 3407）的结果，
其中 **123 与 2026** 为未计入正文汇报的种子（badcase），完整数据如下。

协议：随机化头 = 随机初始化（randn ×0.01）+ 逐 epoch 洗牌的 mini-batch（256）
+ 特征 dropout（p=0.1）；验证集选点；特征与主论文完全一致。

## 3. 锚点（BEATs / WavLM）随机化对照（口径对称性记录）

主论文锚点采用 LR 凸求解（确定性，无种子方差）。以下为同款正则化头
（三随机源）下的锚点结果，供口径对照：

| 锚点 | LR 确定性 | 正则化头 5-seed mean±std | 明细 |
|---|---|---|---|
| BEATs (L9) | 0.7434 | **0.7566 ± 0.0017** | 0.7587/0.7579/0.7549/0.7549/0.7564 |
| WavLM (L8) | 0.7084 | **0.7168 ± 0.0012** | 0.7169/0.7169/0.7147/0.7177/0.7177 |

正则化头对锚点亦有 +0.8~+1.3pt 增益；对称口径下 BEATs（0.7566）
与七源融合正则化头（0.7495）差距 0.7pt（McNemar p=0.54，不显著）。

## 4. 统计检验记录（融合 3-seed 平均概率集成 vs BEATs LR）

- 融合集成 0.7490 vs BEATs 0.7434
- 差值 90% CI（录音聚类 10,000 重采样）：[−2.2, +3.2] pt
- ±2pt 等效判定：不成立（CI 跨出边际）；McNemar 精确 p = 0.54
- 主论文因此采用"差异不显著"表述而非等效/超过声明

## 5. 确定性对照（零初始化全批量，无随机源）

零初始化 + 全批量 + 无 dropout 下，五个种子的层加权结果完全相同
（0.7099，std = 0.0000）——训练本身无随机源；随机化头引入的方差
（±0.005）即上表所列。3k 训练子集重抽的方差为 ±0.0045（0.692–0.703）。
